2. Authenticated Request Sequence

sequenceDiagram participant C as 👤 Client participant F as JwtAuthenticationFilter participant SC as SecurityContextHolder participant AC as AuthController participant AS as AuthServiceImpl participant JP as JwtTokenProvider participant DP as DaoAuthenticationProvider participant UDS as CustomUserDetailsService participant DB as UserRepository Note over C,DB: ── Register / Login Flow ── C->>F: POST /api/auth/login {email, password} F->>F: No Bearer token → skip JWT check F->>AC: Forward request AC->>AS: login(LoginRequest) AS->>DP: authenticate(email, password) DP->>UDS: loadUserByUsername(email) UDS->>DB: findByEmail(email) DB-->>UDS: User entity (implements UserDetails) UDS-->>DP: UserDetails DP->>DP: BCrypt.matches(rawPwd, encodedPwd) DP-->>AS: Authentication principal=UserDetails AS->>JP: generateAccessToken(userDetails) JP-->>AS: JWT access token (24h, HS256 + role claim) AS->>JP: generateRefreshToken(userDetails) JP-->>AS: JWT refresh token (7d, HS256) AS-->>AC: AuthResponse AC-->>C: 200 OK {accessToken, refreshToken, tokenType, expiresIn} Note over C,DB: ── Protected Resource Request ── C->>F: GET /api/student/1 Authorization: Bearer {accessToken} F->>F: extractJwtFromRequest() → token F->>JP: extractUsername(token) JP-->>F: email (subject claim) F->>JP: isTokenValid(token, email) JP->>JP: check signature + expiry JP-->>F: true F->>UDS: loadUserByUsername(email) UDS->>DB: findByEmail(email) DB-->>UDS: User entity UDS-->>F: UserDetails F->>SC: setAuthentication(UsernamePasswordAuthenticationToken) F->>AC: Forward request (authenticated) AC-->>C: 200 OK {student data} Note over C,DB: ── Expired / Invalid Token ── C->>F: GET /api/student/1 Authorization: Bearer {badToken} F->>JP: extractUsername(token) / isTokenValid() JP-->>F: exception / false F->>F: Log error, skip setAuthentication F->>AC: Forward (no auth set) AC-->>C: 401 Unauthorized
